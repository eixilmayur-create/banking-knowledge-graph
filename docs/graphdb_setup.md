# GraphDB Setup

## Repository

Repository ID:

banking-kg

Purpose:

Store and query the RDF Banking Knowledge Graph.

## Data Loaded

- Banking ontology
- Golden Customers
- Bank Accounts
- Cards
- Loans
- Transactions
- Branches

## Query Language

SPARQL

## Primary Use Cases

- Semantic querying
- Customer 360
- Relationship traversal
- Data-quality analysis
- Ontology reasoning
- Graph exploration

## Data Pipeline

CSV
→ Cleaning
→ Entity Resolution
→ RDF
→ GraphDB
→ SPARQL
